# Park Buddies 🌿

> 因为好奇，走进上海的公园，发现身边的植物朋友。

Park Buddies 是一款通过"好奇心"鼓励居民走进上海公园、观察植物、探索不同角落的互动 Web 应用。核心体验循环：**产生好奇 → 进入公园 → 自由探索 → 注意到植物 → 拍照验证 → 了解植物 → 解锁伙伴 → 继续探索**。

产品以观察和发现为核心，不做倒计时、强制打卡、步数排名或竞争排行榜——数字花园只是探索现实世界之后的延续。

## 功能特性

- **探索首页**：公园地图 / 列表双视图，按名称搜索、按行政区筛选，附近公园提示
- **公园探索页**：公园主题色视觉氛围、植物线索卡片、发现进度、吉祥物三态展示
- **植物线索页**：剪影与模糊线索文案，"我好像发现了"拍照入口
- **拍照验证**：后置摄像头拍摄 / 相册上传，完整验证状态机（成功 / 未匹配 / 无法判断 / 网络失败）
- **发现成功页**：庆祝动效、植物档案（有趣知识、知识来源、下次观察建议）、奖励进度
- **数字花园**：已解锁伙伴展示，支持喂食、换装、装饰的轻养成玩法
- **发现记录**：按公园筛选的发现历史
- **我的**：昵称设置、探索统计、权限说明、数据删除入口

## 技术栈

| 分类 | 选型 |
|------|------|
| 前端框架 | React 18 + TypeScript + Vite |
| 样式 | Tailwind CSS 3 |
| 状态管理 | Zustand |
| 路由 | react-router-dom |
| 图标 | lucide-react |
| 数据存储 | localStorage（结构化数据）+ IndexedDB（照片） |

架构采用分层设计：页面展示层 → 状态管理层 → 服务接口层 → 演示实现 / 真实服务适配。MVP 阶段无后端，通过服务接口层隔离真实服务，后续可平滑替换。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

浏览器访问 http://localhost:5173/

> 注意：这是 Vite 项目，`index.html` 需要通过开发服务器打开，直接双击文件会白屏。

### 其他命令

```bash
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览构建产物
npm run lint     # ESLint 检查
npm run check    # 仅 TypeScript 类型检查
```

## 演示模式说明

- 无 API Key 或后端时，应用运行在明确标注的**演示模式**下
- 演示数据、演示地图、模拟识别结果均有"演示"标识
- 演示解锁记录（`isDemo: true`）与正式收藏分开保存
- 真实服务接入后，验证和奖励判定将在服务端执行

## 项目结构

```
src/
├── components/   # 通用组件（底导航、相机、吉祥物插画等）
├── pages/        # 8 个页面
├── store/        # Zustand 全局状态
├── services/     # 服务接口层（演示实现 + 真实服务预留）
├── data/         # 公园与植物静态数据
├── hooks/        # 相机等自定义 hooks
├── models/       # TypeScript 类型定义
└── lib/          # 工具函数
```
